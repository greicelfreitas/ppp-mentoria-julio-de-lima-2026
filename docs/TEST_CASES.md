# Casos de teste

CT001–CT006 cobrem unidade: busca, identificação e duplicidade. CT007–CT014 cobrem integração: listagem, consulta, IDs, parâmetros, JSON e Content-Type. CT015–CT021 cobrem contrato: obrigatórios, espaços, formato, tipos e propriedades adicionais. CT022–CT028 são E2E HTTP: cadastro, consulta, identificação, listagem, duplicidade, inexistente e payload inválido. Todos são automatizados; os 28 cenários incluem sucessos, erros e limites definidos no contrato.
